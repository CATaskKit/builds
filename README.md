release assets. It contains no source code.

**The place to get these tools is [cataskkit.com](https://www.cataskkit.com),**
where each one has a description, what it needs to run, and a walkthrough
where there is one. The permanent download links look like this and always

## About the files

Builds come in several shapes, because the tools do:

- **Installers** (`.exe`) — run it, and the tool is installed.
- **Portable programs** (`.exe`) — no installation; run the file where it is.
- **Excel tools** (`.xlsm`) — macros must be enabled for these to work.
- **One browser tool** (`.html`) — save it and open it in your browser. It
  runs on your own machine; nothing is uploaded.

Everything here runs on your own computer. No file you open in one of these
tools is sent anywhere.

## Updates

A tool is updated by replacing the file in its release. Some tools keep their
older builds alongside the current one; others are replaced outright, because
an older build of them has no use.
